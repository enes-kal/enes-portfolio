# Enes Portfolio

Aygün Dev tarzından ilham alan, React + Vite ile hazırlanmış kişisel portfolyo sitesi.

## Kurulum

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## GitHub'a yükleme

```bash
git init
git add .
git commit -m "Initial portfolio website"
git branch -M main
git remote add origin https://github.com/myeneskal/enes-portfolio.git
git push -u origin main
```

## Netlify / Vercel

- Build command: `npm run build`
- Publish directory: `dist`

## Düzenlenecek alanlar

`src/main.jsx` içindeki `profile`, `experiences`, `projects` ve `skills` alanlarını kendine göre düzenleyebilirsin.
